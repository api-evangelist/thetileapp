# Tile (thetileapp)

> Tile is a consumer Bluetooth-tracker company (Tile Mate, Pro, Slim, and Sticker
> devices plus the "Find" crowd-locate network) added to the API Evangelist network
> as a portfolio-lead stub. Tile was acquired by Life360 in 2021. Tile does not
> publish an official public developer API or developer portal; this profile
> captures the company's public web and security-program surface only.

## Notes for agents
- There is no official Tile developer API, OpenAPI spec, SDK, or MCP server. Third-party
  community libraries (e.g. pytile, tile.net) exist but wrap Tile's private, unofficial
  app API and are not first-party or supported.
